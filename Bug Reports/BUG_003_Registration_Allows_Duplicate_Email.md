# BUG-003: System Allows Registration Using Existing Email

## Environment
- Browser: Google Chrome
- Operating System: Windows 11

## Severity
Medium

## Priority
High

## Preconditions
An existing account with the email address is available.

## Steps to Reproduce
1. Open the registration page.
2. Enter an existing email address.
3. Complete all required information.
4. Click Register.

## Expected Result
The system should display an error message indicating that the email already exists.

## Actual Result
The system successfully creates a new account using the same email.

## Status
Open
