# QA E-Commerce Testing Portfolio

## Project Overview

This repository demonstrates my practical QA testing skills through a sample e-commerce web application testing project.

The objective of this project is to simulate a real-world QA testing workflow, including requirement analysis, test case design, defect reporting, API testing, and test execution reporting.

This portfolio was created to strengthen my transition from Software Development to Quality Assurance, leveraging my background in enterprise application development and system troubleshooting.

---

## Testing Scope

The following application modules are covered:

### 1. User Authentication
- Login
- Registration
- Password validation
- Input field validation

### 2. Shopping Features
- Product browsing
- Add to cart
- Update cart quantity
- Remove items from cart

### 3. Checkout Process
- Shipping information validation
- Payment flow validation
- Order confirmation

---

## Testing Activities

### Manual Testing
- Designed detailed test cases based on functional requirements.
- Performed positive and negative testing scenarios.
- Validated expected results against actual application behavior.

### Defect Reporting
- Documented defects with:
  - Bug ID
  - Title
  - Severity & Priority
  - Steps to reproduce
  - Expected result
  - Actual result

### API Testing
Performed API testing using Postman:
- GET requests validation
- POST requests validation
- HTTP status code verification
- JSON response validation

### Test Execution Reporting
Created testing summary reports including:
- Total test cases executed
- Passed/failed test cases
- Defect summary
- Testing conclusion
